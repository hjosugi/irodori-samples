# Sample query projects

Engine-specific queries for manual checks in Irodori Table.

```sh
make db-up DB=postgres
# connect in Irodori Table, then run projects/postgres/queries.sql
make db-down DB=postgres
```

The catalog is `../db-feature-samples.json`.
